Добро пожаловать в LMSH

Краткий гид по новым возможностям

  • Нажмите History (или свайп справа налево) — откроется список ваших историй.
  • Каждая история автоматически сохраняется в браузере.
  • Три точки → переименовать, отправить в Fast Assistant или удалить.
  • Кнопка Таблица добавляет ячейки для сравнений. ПКМ по таблице → «Убрать таблицу».
  • Тема переключается кнопкой в верхней панели.
