Flow Assistant

Локальный штаб ЛМСХ для работы с нейросетями. Чаты, файлы, поиск в интернете, истории и настройки — всё в браузере, без сервера.

info Что это

LMSH Flow (Flow Assistant) — клиент для ИИ, заточенный под Штаб ЛМСХ. Ключи API и история хранятся только у вас в localStorage. Нет облачного аккаунта Штаба — данные не уходят на сторонний бэкенд приложения.

hub Модели

Основной провайдер — Google Gemini (API Studio). В настройках заложены слоты под Claude, ChatGPT и Grok; сейчас в ядре реализован запрос к Gemini.

gemini-2.5-flash gemini-2.5-pro gemini-2.0-flash gemini-3.x

security Приватность

  • API-ключ хранится только в браузере.
  • Запросы уходят напрямую к API провайдера (например, Google).
  • Нет обязательной регистрации в Flow.
  • Сброс системы в настройках удаляет все локальные данные lmsh_*.

groups Штаб ЛМСХ

Проект заточен под роли Штаба (Ламирк, Мурзик, Снежинка, Хахми) и персональный контекст. Промпты и «память» настраиваются во вкладке «О вас».

handshake Лицензия и ответственность

Flow Assistant — локальный инструмент. Использование API подчиняется правилам выбранного провайдера. Авторы Штаба не хранят ваши ключи и переписку на своих серверах в рамках этого клиента.
